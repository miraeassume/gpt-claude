# KOFIA 국고채권 금리 조회 웹사이트 프로토타입

## 실행 방법
1. `index.html`을 브라우저로 엽니다.
2. 기준일을 선택하고 `샘플 조회`를 누릅니다.
3. `요청 XML 보기`로 KOFIA API에 보낼 XML 구조를 확인합니다.
4. `CSV 다운로드`로 현재 화면의 결과를 저장합니다.

## 현재 버전의 성격
- 업로드된 `KOFIA 국고채권 금리 수집 가이드.md`를 바탕으로 만든 정적 웹사이트 프로토타입입니다.
- 브라우저에서 KOFIA XML API를 직접 호출하면 CORS 또는 사내망 정책으로 실패할 수 있습니다.
- 실제 운영형 웹사이트는 Flask/FastAPI 같은 백엔드에서 KOFIA API를 호출하고, 화면은 그 결과만 받아오는 구조를 권장합니다.

## 운영형 확장 방향
- `/api/rate?date=YYYYMMDD` 백엔드 API 추가
- 날짜 범위 조회
- 영업일/공휴일 처리
- 엑셀 다운로드
- 조회 로그 저장
- 사내망 프록시/방화벽 정책 반영
